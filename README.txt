# 내 주식 대시보드

## 현재 포함된 기능
- 모바일/PC 반응형 혼합형 대시보드
- 주요 종목 카드와 전체 종목 표
- 종목 추가/수정/삭제, 수량·평단·현재가 입력
- 손익 및 수익률 자동 계산
- 한국 원화(KRW)와 미국 달러(USD) 합계를 분리 표시
- 여러 계좌 별칭 및 증권사 선택 설정
- JSON 백업 내보내기/가져오기
- PWA 기본 파일(manifest, service worker, 아이콘)

## 실행
1. ZIP 압축을 풉니다.
2. `index.html`을 브라우저에서 열면 기본 기능을 사용할 수 있습니다.
3. 홈 화면 앱 설치(PWA)는 HTTPS로 호스팅한 뒤 갤럭시 Chrome에서 사이트 메뉴 > 앱 설치 또는 홈 화면에 추가를 사용하세요.

## 중요한 제한
현재 버전은 작동하는 프런트엔드 프로토타입입니다. 가격은 사용자가 직접 입력해야 합니다.
- 실시간 시세: 시세 제공사 API 키와 서버 연동 필요
- 증권사 자동 계좌연동: 증권사별 공식 API/개인 계좌 권한/인증 흐름 확인 및 서버 구현 필요
- 기기 간 동기화: 로그인, 클라우드 DB, 보안 규칙 및 HTTPS 배포 필요

증권사 설정은 앱 안에서 언제든 선택/변경할 수 있게 되어 있습니다. 선택만으로 계좌가 자동 연결되는 것은 아닙니다. 계좌 비밀번호, OTP, 인증서 비밀정보를 이 HTML 파일에 입력하지 마세요.
